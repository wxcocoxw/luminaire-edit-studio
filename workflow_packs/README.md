# Workflow packs

Luminaire Edit Studio shares image-processing and delivery tools across
model-specific workflow packs. Install the repository once as a ComfyUI node pack,
then import a supported pack's canvas.

| Pack | Status | Guide |
| --- | --- | --- |
| Qwen Image 2.1 (`qwen21`) | Supported | [Install and use](qwen21/README.md) |

No additional generation engine is bundled. See [support](../docs/SUPPORT.md) for
capabilities and limits, and [pack layout](../docs/WORKFLOW_PACKS.md) for sources.
