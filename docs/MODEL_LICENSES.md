# Model licenses

Luminaire Edit Studio's original code and workflow contributions are licensed
under [GPL-3.0-only](../LICENSE). Model weights and external node implementations
are downloaded separately and retain their publishers' terms.

## Model use

- **Qwen Image 2.1:** the published agreement permits research/evaluation use.
  Commercial use requires a separate grant from the model publisher. Read the
  [official model license](https://huggingface.co/Qwen/Qwen-Image-2.1/blob/main/LICENSE).
- **Viggle Turbo:** the publisher identifies the same research-only model terms.
  See the [model card's license section](https://huggingface.co/Viggle/Qwen-Image-2.1-viggle-turbo/blob/main/README.md#license).
- **Encoders, VAEs, adapters and upscalers:** check the license for each asset you
  select. One asset's terms do not automatically apply to another.

Review the agreement supplied with the exact file/version you use and any
separate authorization you already hold. Quantizing a model or changing its
loader does not itself supply additional usage rights.

## Project and dependency scope

The project's GPL license does not replace a model agreement or grant trademark
rights. No model weights are included in this repository or its release archive.

External node packs are installed separately; follow each publisher's license
and installation instructions. See [Dependencies](DEPENDENCIES.md),
[third-party notices](../NOTICE.md), and [sources and credits](../SOURCES.md).
