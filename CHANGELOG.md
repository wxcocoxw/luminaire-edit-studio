# Changelog

## 1.4.0

Initial public release of Luminaire Edit Studio.

- Qwen Image 2.1 workflow pack with eight editing, generation and finishing tasks.
- Shared pixel-protection, mask, preview, delivery, alpha, upscaling and grain tools.
- Optional Viggle six-step Draft mode and Auto/PyTorch/Comfy Kitchen/SageAttention selection.
- Resumable batch processing with saved job state and API templates.
- Windows Portable installer with model-pack selection and duplicate-install checks.
- GPL-3.0-only project license; model weights and external nodes installed separately.
